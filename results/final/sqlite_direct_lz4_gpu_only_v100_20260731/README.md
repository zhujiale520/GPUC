# SQLite 真实 LZ4 严格 GPU-only 对照

与混合分流目录使用同一真实LZ4 fixture和查询口径，但设置
`GPUC_LZ4_SMALL_READ_CPU_BLOCKS=0`，所有压缩block都提交到V100。

| 路径 | QPS | 95% CI | p99 us | 95% CI | host cores |
|---|---:|---:|---:|---:|---:|
| 普通文件 | 22606.95 | ±30.34 | 100.66 | ±0.69 | 1.085 |
| CPU LZ4 | 108.92 | ±0.30 | 12407.77 | ±142.16 | 1.036 |
| GPU-only LZ4 | 55.67 | ±1.33 | 24473.48 | ±339.86 | 0.696 |

GPU-only主机CPU较低，但吞吐约为CPU LZ4的51.1%，不是公平同工作量卸载收益。
