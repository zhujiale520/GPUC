# mmap 正确性与延迟复测（2026-07-25）

测试使用每页不同的确定性非零 pattern。`mmap()` 返回后不等待，立即扫描每一页并
校验，因此能发现旧后台填充实现的尾部未就绪问题。

| 大小 | 方案 | mmap 返回 ms | 全页扫描 ms | mismatches |
|---|---|---:|---:|---:|
| 64 MiB | Baseline | 0.004 | 6.998 | 0 |
| 64 MiB | Hook RAW | 46.782 | 0.953 | 0 |
| 64 MiB | GPU Compressed | 427.839 | 0.431 | 0 |
| 256 MiB | Baseline | 0.003 | 26.454 | 0 |
| 256 MiB | Hook RAW | 157.952 | 2.149 | 0 |
| 256 MiB | GPU Compressed | 1210.039 | 1.772 | 0 |

当前实现返回前同步填充全部匿名映射，正确性通过，但 256 MiB GPU Compressed
返回延迟约 1.21 s。旧报告的 231 ms 是后台仍在写入时过早返回，不可继续使用。
后续若要兼顾正确性与返回延迟，需要 `userfaultfd` 等真正缺页驱动方案。
